## 🚀 Quick Start

1. **Download** all game files
2. **Extract** all folders into one directory
3. **Open** the folder in Visual Studio Code
4. **Right-click** on `tictactoe.html` and select "Open with Live Server"
5. **Enjoy** losing to Mr. Robot! 😉

## 🎮 How to Play

- **You play as:** ❌ (X)
- **Mr. Robot plays as:** ⭕ (O)
- Click on any empty cell to make your move
- Try to get 3 in a row (horizontally, vertically, or diagonally)
- The game includes timers, score tracking, and animated emoji reactions!

## ✨ Game Features

### 🎮 Multiple Game Modes:
- **🤖 vs AI** - Play against Mr. Robot with adjustable difficulty
- **👥 2 Players** - Local multiplayer with a friend

### ⚙️ Flexible Game Settings:
- **🎯 Choose who starts first** (X or O or Random)
- **⚙️ Adjustable difficulty levels** (Easy, Medium, Hard)
- **⏱️ Custom timer settings** for total game time
- **🔇 Sound controls** - toggle move sounds on/off

### 🎭 Game Experience:
- **😄 Animated emoji reactions** for wins, losses, and draws
- **⏰ Dual timers** tracking both players' thinking time
- **📊 Score tracking** with persistent storage (saves between sessions)
- **📱 Fully responsive design** - plays perfectly on desktop, tablet, and mobile
